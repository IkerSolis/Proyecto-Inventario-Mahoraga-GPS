GUIA PASO A PASO: COMO SUBIR CAMBIOS Y TRABAJAR EN EQUIPO EN GITHUB
===================================================================

Sigue este ciclo cada vez que vayas a trabajar en una nueva tarea, archivo o corrección.

PASO 1: ASEGURATE DE ESTAR ACTUALIZADO
Siempre antes de empezar a trabajar, asegúrate de tener la última versión del código.
Abre tu terminal y ejecuta:
> git checkout main
> git pull origin main

PASO 2: CREA TU RAMA DE TRABAJO (BRANCH)
Nunca trabajes en la rama "main". Crea una rama con un nombre que describa tu tarea.
Ejemplos: feature/login, bugfix/boton-roto, docs/readme.
> git checkout -b feature/nombre-de-tu-tarea

PASO 3: TRABAJA EN TUS ARCHIVOS
Crea, edita o elimina los archivos necesarios en tu editor de código.

PASO 4: PREPARA TUS CAMBIOS (ADD)
Cuando termines una parte de tu trabajo, dile a Git qué archivos quieres preparar para guardar.
Para preparar TODOS los archivos modificados:
> git add .
(O para un archivo especifico: git add nombre_del_archivo.txt)

PASO 5: GUARDA TUS CAMBIOS LOCALMENTE (COMMIT)
Guarda los archivos preparados con un mensaje claro y descriptivo.
> git commit -m "feat: agrega el nuevo archivo de configuracion"

*Nota: Puedes repetir los Pasos 3, 4 y 5 varias veces en tu rama.*

PASO 6: SUBE TUS CAMBIOS A GITHUB (PUSH)
Sube tu rama al servidor de GitHub para que el equipo pueda verla.
> git push origin feature/nombre-de-tu-tarea

PASO 7: CREA EL PULL REQUEST (PR)
1. Ve a la página de tu repositorio en GitHub.com.
2. Verás un banner amarillo/verde sugiriendo crear un "Pull request", haz clic ahí (o ve a la pestaña Pull Requests -> New Pull Request).
3. Asegúrate de que estás comparando tu rama contra "main".
4. Escribe un título y descripción de lo que hiciste.
5. Haz clic en "Create pull request".

PASO 8: REVISION Y MERGE
1. Tu equipo revisará el código en GitHub.
2. Si te piden cambios, hazlos en tu PC, haz "git add ." y "git commit", luego "git push". El PR se actualiza solo.
3. Cuando sea aprobado, alguien (o tú) dará clic en "Merge pull request" en GitHub.

PASO 9: LIMPIEZA FINAL
Una vez que tus cambios están integrados en "main" en GitHub, limpia tu computadora:
> git checkout main
> git pull origin main
> git branch -d feature/nombre-de-tu-tarea

¡Listo! Ya puedes volver al Paso 1 para tu siguiente tarea.
